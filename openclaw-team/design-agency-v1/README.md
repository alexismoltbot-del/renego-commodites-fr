# ReneGo Design Agency v1

Equipe isolee de recherche + design pour produire plusieurs directions de front
web sans toucher au flow live de lancement.

Objectif:

- identifier les acteurs US les plus solides sur la renegociation / gestion de
  bills et subscriptions;
- extraire les patterns produits, GTM et design qui semblent fonctionner;
- produire 4 variantes de front visibles dans `public/design-lab/`;
- laisser le sprint launch principal intact.

Perimetre:

- recherche US sourcee et datee;
- prototypes statiques HTML/CSS uniquement;
- inspirations visuelles "best in class", pas de copie pixel-perfect ni de
  reprise de marques/copy proprietaires;
- aucun changement sur `/` tant qu'une variante n'est pas choisie.
